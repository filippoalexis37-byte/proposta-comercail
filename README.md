# Santos MktPro — Central Comercial & Propostas

Plataforma de inteligência comercial e geração de propostas consultivas para a Santos MktPro.

## Módulos Inclusos:
- **Propostas Comerciais Consultivas** (Detalhamento profundo por nicho, eliminando orçamentos rasos).
- **Estratégias Específicas por Nicho** (Compra de Ouro, Serralheria, Hamburgueria, Ar-Condicionado, etc.).
- **Rodapé Institucional com Direitos Autorais** (© 2026 Santos MktPro).
- **Gerador de PDF de Alta Precisão** (Renderização A4 pronta para impressão e download).

## Como Rodar:
```bash
npm install
npm run dev
```
